.polyhedra should be able to use other .polyhedra



ways to include another PolyHedra

static:
	put the data from the other PolyHedra into the data of this PolyHedra
	+ only one Buffer
	- more difficult to seperate

dynamic:
	store a List of other PolyHedra
	+ they remain seperate
	+ can be optimized if included multiple times
	- needs extra Buffer for each one
